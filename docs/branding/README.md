# Sniper-Icon

Eigenes Motiv: Fadenkreuz mit Preisschild, in der Akzentfarbe der Oberfläche.

- `icon.svg`: abgerundet, für Browser-Tab und Web-App (liegt auch unter `src/sniper/web/static/`)
- `icon-square.svg`: randlos, für Stellen, die selbst rund oder abgerundet zuschneiden (iOS, Telegram)
- `telegram-bot-sniper.png`: 640 × 640, Profilbild für den Telegram-Bot

Telegram-Bot-Bild setzen: in Telegram @BotFather → `/setuserpic` → Bot auswählen → `telegram-bot-sniper.png` schicken.
